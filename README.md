## What it does

`main.py` writes one short text (under 280 characters) to `/output/entry.txt`.
The text is a quiet scene — a dog asleep against your leg, her whole weight
set down — meant to slow the reader down and leave them with the feeling of
being held, with nothing to prove.

## How to run

```sh
python3 main.py
```

This creates `/output/entry.txt` (UTF-8). The program uses only the Python
standard library, makes no network calls, and is fully deterministic: every
run writes byte-identical output.

## The text

> The dog sighs in her sleep and leans a little harder against your leg, warm and certain, as if you were the place she chose to set her whole weight down. Outside, the light thins. Inside, nothing is asked of you at all.
